Substitution-class decomposition of the trained filter banks
==========================================================================

Each gauge-fixed kernel position decomposes exactly onto the three 2|2 partitions
of {A,C,G,T}; the shares sum to 1 and 1/3 is the null (a single-nucleotide preference
spreads evenly). An axis above 1/3 means the model grouped those nucleotides together,
i.e. made itself blind to the substitutions inside each group.

--- channel-order control: does the preference follow letters or slots? ---
Each control run is paired by name with the A/C/G/T run of the same gene,
architecture and seed (identical initial weights, assigned to different
letters). The slot-order row reads the control's channels as if they were
A/C/G/T; it is the true-letter row relabelled, shown so the swap is visible,
not a second independent test. Shares are mean ± SD over paired seeds.
